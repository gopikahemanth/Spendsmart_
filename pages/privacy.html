Privacy Policy

Last updated: January 2026

Welcome to SpendSmart, a personal expense tracking application designed to help users manage their financial habits in a simple and secure way.

This Privacy Policy explains how SpendSmart collects, stores, and uses information when you use the application.

By using SpendSmart, you agree to the practices described in this Privacy Policy.

1. Information We Collect

SpendSmart collects only the minimum information necessary for the application to function.

Account Information

When you create an account, the following information may be collected:

  • Username
  • Password
  • Optional name (if provided by the user)

This information is used to create and manage your account.

Financial Information

When using SpendSmart, the following information may be stored:

  • Income entries
  • Expense entries
  • Transaction titles
  • Categories
  • Budget values
  • Dates and timestamps of transactions
  • User preferences and settings

2. How Your Data Is Stored

SpendSmart uses secure cloud services provided by Firebase, a platform operated by Google.

User data may be stored using Firebase services such as:

  • Firebase Authentication for account management
  • Firebase Firestore or Realtime Database for storing application data

Firebase infrastructure is designed to provide secure and scalable cloud storage.

3. Data Security

We take reasonable steps to protect your information. Security measures may include:

  • Secure authentication systems
  • Encrypted communication using HTTPS
  • Access control rules within the database

However, no online system can guarantee complete security. Users are encouraged to keep their login credentials confidential.

4. How We Use Data

Collected data may be used to:

  • Provide expense tracking functionality
  • Save user transactions and budgets
  • Manage user accounts
  • Improve application features

SpendSmart does not sell or rent user data to third parties.

5. Third-Party Services

SpendSmart may rely on third-party services to operate the application, including services provided by Google and Firebase.

These services may process information according to their own privacy policies.

6. Data Retention

User data remains stored while the account is active.

If a user deletes their account, associated data may be removed from the system within a reasonable time.

7. User Control

Users may control their data through application features such as:

  • Editing profile information
  • Exporting transaction data
  • Deleting transactions
  • Deleting their account

8. Children's Privacy

SpendSmart is not intended for children under the age of 13. We do not knowingly collect personal information from children.

9. Updates to This Policy

This Privacy Policy may be updated periodically to reflect changes to the application or services used.

When updates occur, the "Last updated" date will be revised.

10. Contact

If you have questions regarding this Privacy Policy, you may contact the SpendSmart team through the contact page.
